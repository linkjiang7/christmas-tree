# 星光圣诞树

在 Windows 双击 `start.cmd`，启动脚本会优先用 Google Chrome 打开 `http://localhost:8077/`。如果该端口已运行本版就直接打开，如果被其他网页占用就换用空闲端口。也可直接打开 `index.html` 体验动画和照片浏览。摄像头手势需要通过 `localhost` 或 HTTPS 打开，并在浏览器中允许访问摄像头。

- 拖动场景可旋转。底部可切换 1 圣诞树、2 星海、3 花环、4 爱心，也可点击树身散开。
- 点击光球或左侧缩略图，照片会飞到页面中央。点击关闭按钮、相框外侧或按 Esc 退出。
- 「放入照片」最多选 16 张，会替换内置的冬日示例。导入的照片保存在当前浏览器中。
- 「开启手势」后，左右手均可识别，可同时放入镜头。收起拇指，伸出 1、2、3、4 根手指并稍作停留，切换对应造型。
- 双手张开后，拉开可放大，靠拢可缩小。单手张掌进入星海，握拳回到圣诞树。移动手掌可旋转，捏合拇指和食指并在光球旁停留可查看照片。
- 切到后台时暂停手势识别，切回时自动继续。关闭页面或点击「关闭手势」会停止摄像头。

部署时将 `index.html`、`style.css`、`scene.js`、`gestures.js`、`photos/` 和 `vision/` 一起上传。手势资源从网页同源路径读取。Windows 启动脚本依赖 Python 3，本地服务只监听本机。
